# Сборка и выпуск Mobile Service Pro

## Вариант 1. Готовый установщик с GitHub (свой ПК для сборки не нужен)

После каждого изменения кода GitHub сам собирает программу на Windows-сервере.

1. Репозиторий на GitHub → вкладка **Actions** → **Build Windows** →
   последний запуск с зелёной галочкой.
2. Внизу страницы, в блоке **Artifacts**:
   - `MobileServicePro-Setup` — установщик;
   - `MobileServicePro-portable` — переносная версия (один .exe).
3. Скачивается zip-архив, внутри него .exe. Файлы хранятся 14 дней.

Запустить сборку вручную: Actions → Build Windows → **Run workflow**.

## Вариант 2. Сборка на своём ПК

1. Установи **.NET 10 SDK**: https://dotnet.microsoft.com/download/dotnet/10.0
2. Для установщика поставь **Inno Setup 6.3+**: https://jrsoftware.org/isdl.php
   или командой `winget install JRSoftware.InnoSetup`.
3. Дважды щёлкни **`build.cmd`** в корне репозитория.

Результат:
```
artifacts\publish\MobileServicePro.exe                   переносная версия (~60 МБ)
artifacts\installer\MobileServicePro-Setup-0.3.0.exe     установщик
```
Без Inno Setup соберётся только переносной .exe — скрипт так и напишет.

Другие способы:
- просто запустить для проверки: `cd MobileServicePro` → `dotnet run`;
- Visual Studio: правый клик по проекту → **Опубликовать** → профиль `win-x64`.

## Что получает мастер

- **Установщик**: выбор «для всех пользователей / только для меня», ярлыки,
  удаление через «Параметры → Приложения».
- **Обновление**: новый установщик ставится поверх старого. Если программа
  открыта, установщик попросит её закрыть.
- **.NET устанавливать не нужно** — он встроен в .exe.
- **adb/fastboot**: при первом запуске кнопка **«Скачать Platform-Tools»**
  загружает официальный архив Google (~8 МБ) в
  `%LOCALAPPDATA%\MobileServicePro\platform-tools`.
- **Логи**: `%LOCALAPPDATA%\MobileServicePro\logs`, кнопка **«Папка логов»**.
  Хранятся 30 дней. Для поддержки мастер присылает файл лога.

## Лицензия Platform-Tools: почему adb не вшит в установщик

Сами adb и fastboot — open source (Apache 2.0). Но архив, который раздаёт
Google, скачивается на условиях лицензии Android SDK, а они ограничивают
распространение третьим лицам. Кроме того, в архиве есть компоненты под GPL
(например, `mke2fs`), а GPL при распространении требует давать и исходный код.

Многие программы всё равно вшивают adb. Но для платного продукта безопаснее,
когда мастер скачивает его сам с dl.google.com — так сделано по умолчанию.

Если всё же решишь вшивать: `build.cmd -BundlePlatformTools`. Это твоё решение;
лучше заранее согласовать с юристом.

## Чеклист перед продажей

1. **Подпись кода.** Без неё Windows SmartScreen показывает «Неизвестный
   издатель» и прячет кнопку запуска за «Подробнее» — мастеров это пугает,
   а антивирусы чаще дают ложные срабатывания. Нужен сертификат подписи кода
   (стоит от нескольких сотен долларов в год, выдаётся на аппаратном токене или
   в облачном HSM). **Важно:** крупные западные удостоверяющие центры, как
   правило, не выдают сертификаты компаниям из России — уточни этот вопрос заранее.
2. **Лицензии и подписки** — следующий этап разработки (см.
   `MobileServicePro/ARCHITECTURE.md`).
3. **Юридическое**: пользовательское соглашение (EULA) или оферта, политика
   конфиденциальности (если хранишь данные клиентов — это персональные данные),
   форма приёма оплаты (самозанятость / ИП / ООО). Шаблон EULA я не вставлял
   сознательно: его должен составить юрист под твою юрисдикцию.
4. **Поддержка**: попроси мастеров присылать файл из «Папки логов».

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `dotnet` не является командой | Установить .NET 10 SDK и открыть новое окно терминала |
| «Inno Setup не найден» | Установить Inno Setup 6.3+ или пользоваться переносным .exe |
| Телефон не виден в ADB | Включить «Отладку по USB», подтвердить запрос на экране телефона, взять кабель с передачей данных |
| Телефон всё равно не виден | Нужен драйвер: многие модели работают на встроенном драйвере Windows, но Samsung, Xiaomi и некоторым другим нужен драйвер производителя или Google USB Driver |
| `adb server version ... doesn't match` | На ПК запущен другой adb (из другой программы). Закрыть ту программу или выполнить `adb kill-server` |
| Состояние `unauthorized` | На телефоне не подтверждена отладка: переподключить кабель и нажать «Разрешить» |
