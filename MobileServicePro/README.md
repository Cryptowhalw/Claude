# Mobile Service Pro — версия 0.2

Windows-приложение для **сервисной диагностики** Android-устройств в мастерской.
Основа будущего коммерческого продукта (подписка для сервис-центров).

> Программа выполняет **только чтение** свойств устройства и использует
> **официальные** Android SDK Platform-Tools (adb/fastboot). Она не снимает
> блокировки (FRP, экранный пароль, Apple Activation Lock), не меняет IMEI и
> не пишет разделы. Прошивка/OEM-unlock выполняются только на устройстве
> владельца штатными средствами производителя.

## Требования
- Windows 10/11
- .NET 10 SDK
- Android SDK Platform-Tools (adb, fastboot) — в папке `tools\platform-tools`
  рядом с программой **или** в `PATH`.

## Запуск
```powershell
cd MobileServicePro
dotnet restore
dotnet run
```

## Сборка автономного EXE
```powershell
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```
Файл появится в `bin\Release\net10.0-windows\win-x64\publish\`.

## Реализовано в 0.2
- Инвентаризация USB-устройств (VID/PID, состояние).
- **ADB-диагностика**: модель, бренд, Android/API, патч безопасности, чипсет,
  ABI, ОЗУ, разрешение экрана, заряд/здоровье/температура батареи, состояние
  bootloader, признак OEM-unlock и root.
- **Fastboot**: чтение `getvar all` — продукт, статус разблокировки,
  возможность OEM-unlock, слоты A/B, версии bootloader/baseband.
- Авто-поиск adb/fastboot рядом с программой или в PATH.
- Экспорт отчёта диагностики в JSON и TXT (для приёмки в ремонт).
- Журнал действий, информация по Apple.

## Дорожная карта (коммерческая версия)
1. **Модуль лицензий/подписок** (клиент + сервер активации) — см. `ARCHITECTURE.md`.
2. Официальная прошивка/OEM-unlock на устройстве владельца (с подтверждением
   и журналированием согласия клиента).
3. Каталог подписанных драйверов VID/PID с проверкой SHA-256.
4. Backup/restore пользовательских данных.
5. Apple-модуль: детект Recovery/DFU, сопровождение официального восстановления.

## Чего программа НЕ делает (принципиально)
- Не снимает FRP / Google-аккаунт, экранные блокировки, iCloud/Activation Lock.
- Не меняет IMEI, не снимает SIM-/оператор-лок.
Это и незаконно в отношении чужих устройств, и технически не является надёжной
функцией на современных Android/iOS.
