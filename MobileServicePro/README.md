# Mobile Service Pro — версия 0.3

Windows-приложение для **сервисной диагностики** Android-устройств в мастерской.
Основа будущего коммерческого продукта (подписка для сервис-центров).

> Программа выполняет **только чтение** свойств устройства и использует
> **официальные** Android SDK Platform-Tools (adb/fastboot). Она не снимает
> блокировки (FRP, экранный пароль, Apple Activation Lock), не меняет IMEI и
> не пишет разделы. Прошивка/OEM-unlock выполняются только на устройстве
> владельца штатными средствами производителя.

## Сборка и установщик
Подробно — в **[BUILD.md](../BUILD.md)**. Коротко:
- готовый установщик собирает GitHub Actions (вкладка Actions → Build Windows);
- или на своём ПК: .NET 10 SDK (+ Inno Setup для установщика) → `build.cmd`.

Для разработки:
```powershell
cd MobileServicePro
dotnet run
```

## Реализовано
**0.3 — готовность к распространению**
- Иконка, сведения о версии и издателе в .exe, манифест (чёткий интерфейс при масштабировании, без прав администратора).
- Автономный однофайловый .exe — у мастера не нужен .NET.
- Установщик Inno Setup: «для всех / только для меня», ярлыки, обновление поверх, корректное удаление.
- Кнопка «Скачать Platform-Tools» — официальный архив Google в `%LOCALAPPDATA%\MobileServicePro\platform-tools`.
- Журнал в файл (`%LOCALAPPDATA%\MobileServicePro\logs`, 30 дней) и кнопка «Папка логов».
- Защита от двойного запуска; непойманные ошибки пишутся в журнал, программа не падает молча.
- Скрипт сборки `build.ps1` / `build.cmd` и сборка в GitHub Actions.

**0.2 — диагностика**
- Инвентаризация USB-устройств (VID/PID, состояние).
- **ADB-диагностика**: модель, бренд, Android/API, патч безопасности, чипсет,
  ABI, ОЗУ, разрешение экрана, заряд/здоровье/температура батареи, состояние
  bootloader, признак OEM-unlock и root.
- **Fastboot**: чтение `getvar all` — продукт, статус разблокировки,
  возможность OEM-unlock, слоты A/B, версии bootloader/baseband.
- Экспорт отчёта диагностики в JSON и TXT (для приёмки в ремонт).

## Структура
```
MobileServicePro/
  App.xaml(.cs)          запуск, защита от двойного запуска, перехват ошибок
  MainWindow.xaml(.cs)   интерфейс
  Core/                  модели данных (USB, Android, Fastboot)
  Services/              ADB, Fastboot, USB, запуск процессов, загрузка Platform-Tools, журнал
  Assets/app.ico         иконка
  tools/platform-tools/  (необязательно) adb для вшивания в сборку
installer/               скрипт установщика Inno Setup
build.ps1, build.cmd     сборка .exe и установщика
```

## Дорожная карта (коммерческая версия)
1. **Модуль лицензий/подписок** (клиент + сервер активации) — см. `ARCHITECTURE.md`.
2. Подпись кода (сертификат) — см. чеклист в `BUILD.md`.
3. Официальная прошивка/OEM-unlock на устройстве владельца (с подтверждением
   и журналированием согласия клиента).
4. Каталог подписанных драйверов VID/PID с проверкой SHA-256.
5. Backup/restore пользовательских данных.
6. Apple-модуль: детект Recovery/DFU, сопровождение официального восстановления.

## Чего программа НЕ делает (принципиально)
- Не снимает FRP / Google-аккаунт, экранные блокировки, iCloud/Activation Lock.
- Не меняет IMEI, не снимает SIM-/оператор-лок.
Это и незаконно в отношении чужих устройств, и технически не является надёжной
функцией на современных Android/iOS.
